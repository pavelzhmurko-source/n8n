# Приймання на Windows

Цей чек-лист виконується на HP Pavilion 14-ce0064ur. Telegram token вводиться
лише у локальне вікно launcher і не копіюється у звіт.

## Перший запуск

- [ ] Docker Desktop показує `Engine running` у режимі Linux containers.
- [ ] Подвійний клік по [start.cmd](start.cmd) відкриває українське вікно.
- [ ] Токен вводиться у масковане поле; після збереження поле очищується.
- [ ] Кнопка пошуку знаходить user ID після приватного повідомлення боту.
- [ ] Перший запуск відкриває n8n для створення локального власника.
- [ ] Друге натискання **Запустити** завершується зеленим станом **готово**.
- [ ] **Відкрити n8n** відкриває `http://127.0.0.1:5678` і штатний логін.

## Telegram і захист

- [ ] `Привіт` повертає `Отримано: Привіт` не довше ніж за 10 секунд.
- [ ] Повідомлення від іншого user ID не отримує навчальну відповідь.
- [ ] Фото або повідомлення з групи не запускає відповідь.
- [ ] У n8n видно одне успішне виконання для одного нового `update_id`.
- [ ] Кнопка **Перевірити** підтверджує n8n і Telegram webhook.
- [ ] Публічні `/`, `/rest/settings` і `/webhook-test/telegram-course` не відкривають редактор або API.

## Повторний запуск і збої

- [ ] Повторне натискання не створює другий workflow або credential.
- [ ] Зміна навчального workflow у n8n зберігається після нового запуску.
- [ ] Після **Зупинити** дані лишаються, а сторонні Docker-контейнери не змінюються.
- [ ] Новий запуск отримує нову адресу tunnel і бот знову відповідає.
- [ ] Із закритим Docker Desktop launcher показує зрозумілу помилку без стану **готово**.
- [ ] Із зайнятим портом 5678 launcher пояснює, що порт треба звільнити.
- [ ] Запуск із папки, у шляху якої є пробіли та кирилиця, працює.

## Backup і навантаження

- [ ] [backup.cmd](backup.cmd) створює ZIP у `Документи\N8nCourseKitBackups`.
- [ ] [restore.cmd](restore.cmd) показує попередження, створює страхову копію й відновлює workflow.
- [ ] Після restore звичайний запуск повертає робочі credentials і workflow.
- [ ] 20 послідовних текстових повідомлень дають 20 відповідей без падіння контейнерів.
- [ ] У диспетчері задач записано приблизне максимальне споживання RAM пакетом.

Результати слід додати до [VALIDATION.md](VALIDATION.md) без токена, webhook
secret, персонального тексту повідомлень або повного вмісту backup.
